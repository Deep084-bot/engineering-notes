# Machine Learning
# What is Machine Learning?
It is a branch of Artificial Intelligence. It is basically making machine learning. Normally we give input into a function and it gives us the output but in machine learning we give both the input and output to the machine and ask it to find a relationship ie a function between the input and output. So, in simple words ML teaches machine/system to think and understand like humans.
Machine Learning is a field of AI where instead of explicitly writing rules, we allow the computer to learn patterns from data.

Traditional Programming

Machine Learning
