# Phase 7 — AI in Finance

> How ML, NLP, LLM agents, and alternative data are applied to markets — and the pipelines that power them.

## Prerequisites

Phase 3 — Fundamental Analysis
Phase 5 — Financial Metrics

## Learning Outcomes

After this phase, you should be able to:

- Explain what ML can (and can't) do for price prediction
- Apply NLP to earnings calls and SEC filings
- Design LLM agents for financial analysis
- Process and evaluate alternative data
- Build sentiment analysis systems
- Architect production financial AI pipelines
