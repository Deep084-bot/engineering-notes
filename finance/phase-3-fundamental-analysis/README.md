# Phase 3 — Fundamental Analysis

> Determine what a company is really worth by analyzing its business, financials, and competitive position.

## Prerequisites

Phase 1 — Foundations
Phase 2 — Financial Statements

## Learning Outcomes

After this phase, you should be able to:

- Compute and interpret valuation ratios (P/E, P/B, EV/EBITDA, P/S)
- Build a discounted cash flow model
- Value a company using comparable company analysis
- Assess a company's competitive moat
- Distinguish growth vs value investing styles
