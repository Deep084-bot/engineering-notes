# Phase 8 — Portfolio & Risk Management

> How to build, measure, protect, and adjust an investment portfolio.

## Prerequisites

Phase 3 — Fundamental Analysis
Phase 5 — Financial Metrics
Phase 6 — Quantitative Finance

## Learning Outcomes

After this phase, you should be able to:

- Apply Modern Portfolio Theory and the efficient frontier
- Build an asset allocation strategy
- Measure portfolio risk (volatility, drawdown, VaR, ratios)
- Understand diversification and its limits
- Rebalance a portfolio
- Minimize taxes on investments
- Construct hedges to protect positions
