# Phase 5 — Financial Metrics & Business Terminology

> The KPIs that matter: SaaS metrics, unit economics, operating efficiency, and how businesses make money.

## Prerequisites

Phase 2 — Financial Statements

## Learning Outcomes

After this phase, you should be able to:

- Compute and interpret SaaS metrics (MRR, ARR, churn, LTV, CAC, NRR)
- Analyze unit economics and payback periods
- Use operating metrics (margins, turnover, cash conversion cycle)
- Track industry-specific KPIs (banking, retail, airlines, etc.)
- Speak business model terminology fluently
