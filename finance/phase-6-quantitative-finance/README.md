# Phase 6 — Quantitative Finance

> The math and models behind markets: probability, derivatives, pricing, risk, and backtesting.

## Prerequisites

Phase 3 — Fundamental Analysis, or Phase 4 — Technical Analysis

## Learning Outcomes

After this phase, you should be able to:

- Apply probability and statistics to returns
- Understand derivatives (futures, options, swaps)
- Explain options pricing models (Black-Scholes, binomial)
- Describe interest rate models
- Compute risk metrics (VaR, Expected Shortfall, drawdown)
- Backtest strategies honestly
