# Phase 4 — Technical Analysis

> Reading price charts to identify trends, momentum, and trading opportunities.

## Prerequisites

Phase 1 — Foundations

## Learning Outcomes

After this phase, you should be able to:

- Read and interpret line, bar, and candlestick charts
- Identify trends, support, resistance, and channels
- Use indicators (MA, RSI, MACD, Bollinger Bands)
- Analyze volume and volume-based indicators (OBV, volume profiles)
- Recognize chart patterns and their breakouts
