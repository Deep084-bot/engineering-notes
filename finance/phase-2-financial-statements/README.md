# Phase 2 — Financial Statements

> The language of business. Learn to read and analyze the three core financial statements that every public company reports.

## Prerequisites

Phase 1 — Foundations

## Learning Outcomes

After this phase, you should be able to:

- Read and interpret a balance sheet
- Understand how the income statement shows profitability
- Analyze cash flow from operations, investing, and financing
- Connect the three statements and spot red flags
- Compute and interpret basic financial ratios
